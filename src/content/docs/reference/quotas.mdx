The three numbers you hit in practice:

    <span class="ecsx-stat__n">250</span>
    <span class="ecsx-stat__label">

| Limit                           | Value  |
| ------------------------------- | ------ |
| Clusters associated per gateway | 10,000 |
| Gateways associated per cluster | 5      |
| Services per shared ALB         | 25     |
| Default `maxAlbCount`           | 10     |

If `maxAlbCount` is reached and every ALB is full, a connecting deployment fails. Raise `maxAlbCount` (via update, including the full configuration you want to keep) before you expect more than `25 × maxAlbCount` services on that gateway.

<Aside type="note">Service-level ECS and ELB quotas still apply (tasks, target groups, certificates per account, and so on).</Aside>
