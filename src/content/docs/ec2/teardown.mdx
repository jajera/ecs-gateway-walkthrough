---
title: EC2 teardown
description: Delete EC2-path services, gateway, instance, and optionally the shared VPC (including NAT) and IAM roles.

Tear down in reverse: remove the services (routes drain, ALB deprovisions), then the gateway, then the instance and cluster, then the EC2 instance IAM. The shared VPC and IAM roles come last — and only if you are finished with **both** paths.

<Aside type="caution">
  Steps 1–4 are **EC2-path only**. Do **not** run the "Shared VPC and roles" section if you still plan to run (or keep) the [Fargate path](/fargate/overview/) — the VPC, NAT, and IAM roles are shared
  by both.
</Aside>

<Aside type="note">Each step shows one command with sample output directly below it. Sample outputs use the lab name `ecs-gw-lab-ec2`; ARNs and account IDs are redacted or omitted.</Aside>

## Path variables

Confirm `$INSTANCE_ID` and `$EC2_SG_ID` from [EC2 capacity](/ec2/capacity/) are still set.

<div class="ecsx-cli">

```bash frame="terminal"
export PATH_NAME="${NAME}-ec2"
export CLUSTER="$PATH_NAME"
export GATEWAY="$PATH_NAME"
echo "path ready: CLUSTER=$CLUSTER GATEWAY=$GATEWAY INSTANCE_ID=${INSTANCE_ID:+set}"
```

```text
path ready: CLUSTER=ecs-gw-lab-ec2 GATEWAY=ecs-gw-lab-ec2 INSTANCE_ID=set
```

</div>

## Wait for routes to clear

Routes (and the shared ALB) go away after the services disconnect. This often takes several minutes.

<div class="ecsx-cli">

```bash frame="terminal"
for i in $(seq 1 60); do
  COUNT=$(aws ecs list-gateway-routes --gateway "$GATEWAY" --cluster "$CLUSTER" \
    --query 'length(gatewayRoutes)' --output text 2>/dev/null || echo 0)
  echo "routes: $COUNT"
  [ "$COUNT" = "0" ] && break
  sleep 15
done
```

```text
routes: 2
routes: 1
routes: 0
```

</div>

## Disable deletion protection

`update-gateway` requires the infrastructure role ARN and a `configuration` object. For a protection-only change, pass an empty `hostSharedAlb`.

<div class="ecsx-cli">

```bash frame="terminal"
aws ecs update-gateway --gateway "$GATEWAY" \
  --infrastructure-role-arn "$GATEWAY_INFRA_ROLE_ARN" \
  --no-deletion-protection \
  --configuration '{"hostSharedAlb":{}}' \
  --query 'gateway.{name:name,deletionProtection:deletionProtection}'
```

```text
{
    "name": "ecs-gw-lab-ec2",
    "deletionProtection": false
}
```

</div>

Wait until the gateway leaves `UPDATE_IN_PROGRESS` before deleting:

<div class="ecsx-cli">

```bash frame="terminal"
for i in $(seq 1 36); do
  STATUS=$(aws ecs describe-gateway --gateway "$GATEWAY" \
    --query 'gateway.status' --output text)
  echo "$i: $STATUS"
  [ "$STATUS" = "UPDATE_COMPLETE" ] && break
  sleep 10
done
```

```text
1: UPDATE_IN_PROGRESS
2: UPDATE_COMPLETE
```

</div>

## Disassociate gateway from cluster

<div class="ecsx-cli">

```bash frame="terminal"
aws ecs disassociate-gateway-from-cluster \
  --gateway "$GATEWAY" \
  --cluster "$CLUSTER" >/dev/null
```

```text
(no stdout — success is silent)
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
for i in $(seq 1 36); do
  ASSOC=$(aws ecs list-gateway-cluster-associations --gateway "$GATEWAY" \
    --query 'length(gatewayClusterAssociations)' --output text 2>/dev/null || echo 0)
  echo "associations: $ASSOC"
  [ "$ASSOC" = "0" ] && break
  sleep 10
done
```

```text
associations: 1
associations: 0
```

</div>

## Deregister task definitions

<div class="ecsx-cli">

```bash frame="terminal"
aws ecs list-task-definitions --family-prefix "$PATH_NAME" \
  --query 'length(taskDefinitionArns)' --output text
```

```text
2
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws ecs list-task-definitions --family-prefix "$PATH_NAME" --query 'taskDefinitionArns[]' \
  --output text | tr '\t' '\n' | while read -r ARN; do
  [ -n "$ARN" ] && aws ecs deregister-task-definition --task-definition "$ARN" >/dev/null
done
echo "deregistered"
```

```text
deregistered
```

</div>

## Shared VPC and roles

Skip this section if you still plan to run (or keep) the [Fargate path](/fargate/gateway/).

<div class="ecsx-cli">

```bash frame="terminal"

  --role-name "${NAME}-gateway-infra" \
  --policy-arn arn:aws:iam::aws:policy/AmazonECSInfrastructureRoleForGatewayHostSharedALB || true
aws iam delete-role --role-name "${NAME}-gateway-infra" || true
echo "gateway infra role removed"
```

```text
gateway infra role removed
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws iam detach-role-policy \
  --role-name "${NAME}-exec" \
  --policy-arn arn:aws:iam::aws:policy/service-role/AmazonECSTaskExecutionRolePolicy || true
aws iam delete-role --role-name "${NAME}-exec" || true
```

```text
exec role removed
```

</div>

### Wait for ENIs

ALB / task / instance ENIs must clear before the VPC can delete.

<div class="ecsx-cli">

```bash frame="terminal"
for i in $(seq 1 36); do
  COUNT=$(aws ec2 describe-network-interfaces \
    --filters "Name=vpc-id,Values=${VPC_ID}" \
    --query 'length(NetworkInterfaces)' --output text)
  echo "ENIs: $COUNT"
  [ "$COUNT" = "0" ] && break
  sleep 10
done
```

```text
ENIs: 3
ENIs: 1
ENIs: 0
```

</div>

### NAT, routes, subnets, VPC

IDs stay in shell variables — do not echo full resource ARNs into tickets.

<div class="ecsx-cli">

```bash frame="terminal"
  --query 'NatGatewayId' --output text
```

```text
nat-<id>
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws ec2 wait nat-gateway-deleted --nat-gateway-ids "$NAT_GW_ID"
echo "NAT deleted"
```

```text
NAT deleted
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws ec2 release-address --allocation-id "$EIP_ALLOC_ID"
echo "EIP released"
```

```text
EIP released
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
for RTB in "$PRIVATE_RTB_ID" "$PUBLIC_RTB_ID"; do
  for ASSOC_ID in $(aws ec2 describe-route-tables --route-table-ids "$RTB" \
    --query 'RouteTables[0].Associations[?SubnetId!=`null`].RouteTableAssociationId' \
    --output text); do
    aws ec2 disassociate-route-table --association-id "$ASSOC_ID"
  done
done
echo "subnet route associations cleared"
```

```text
subnet route associations cleared
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws ec2 delete-route --route-table-id "$PRIVATE_RTB_ID" --destination-cidr-block 0.0.0.0/0 || true
aws ec2 delete-route-table --route-table-id "$PRIVATE_RTB_ID"
aws ec2 delete-route --route-table-id "$PUBLIC_RTB_ID" --destination-cidr-block 0.0.0.0/0 || true
aws ec2 delete-route-table --route-table-id "$PUBLIC_RTB_ID"
echo "route tables deleted"
```

```text
route tables deleted
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws ec2 detach-internet-gateway --internet-gateway-id "$IGW_ID" --vpc-id "$VPC_ID"
aws ec2 delete-internet-gateway --internet-gateway-id "$IGW_ID"
echo "IGW deleted"
```

```text
IGW deleted
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws ec2 delete-subnet --subnet-id "$PRIVATE_SUBNET_A"
aws ec2 delete-subnet --subnet-id "$PRIVATE_SUBNET_B"
aws ec2 delete-subnet --subnet-id "$PUBLIC_SUBNET_A"
aws ec2 delete-subnet --subnet-id "$PUBLIC_SUBNET_B"
echo "subnets deleted"
```

```text
subnets deleted
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws ec2 delete-vpc --vpc-id "$VPC_ID"
echo "VPC deleted"
```

```text

```

</div>

<Aside type="caution">If `delete-vpc` fails, wait for ENIs (ALB/tasks/instance) and the NAT gateway to clear. Do not strip `AmazonECSManaged=true` tags while ECS still owns resources.</Aside>
