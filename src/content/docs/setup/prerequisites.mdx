## AWS CLI and Region

You need AWS CLI **2.38.3** or later. That is the first v2 release with `create-gateway` and the other ECS Gateway commands. CLI v1 never includes these commands.

<Tabs syncKey="os">
  <TabItem label="macOS">

```bash
brew install awscli
# already installed: brew upgrade awscli
```

  </TabItem>
  <TabItem label="Linux">

Install `unzip` and `curl` first if needed (`sudo apt install -y unzip curl` or `sudo dnf install -y unzip curl`).

```bash
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install --update
```

ARM:

```bash
curl "https://awscli.amazonaws.com/awscli-exe-linux-aarch64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install --update
```

  </TabItem>
</Tabs>

```bash
aws --version
aws sts get-caller-identity >/dev/null
aws ecs create-gateway help
```

`aws --version` must show `aws-cli/2.38.3` or newer. If `help` says the command is invalid, the CLI is too old. `get-caller-identity` only checks that you are signed in; redirect keeps account details out of the terminal scrollback you might copy.

ECS Gateway is available in **all commercial Regions**. Credentials must be able to call ECS, EC2, IAM, and ELB in the Region where you run the lab. The lab uses `ap-southeast-6` (Asia Pacific — New Zealand). Opt in that Region on the account if it is not already enabled.

## Shell variables

Keep one shell for the whole lab. Later pages reuse these names.

```bash
export AWS_PAGER=""
export AWS_REGION=ap-southeast-6
export AWS_DEFAULT_REGION="$AWS_REGION"
export NAME=ecs-gw-lab

aws sts get-caller-identity >/dev/null
echo "Authenticated. region=$AWS_REGION NAME=$NAME"
```

Confirm you are signed in. Do not paste account IDs, ARNs, or other identity output into issues, PRs, or docs.

<Aside type="caution">
  This lab creates a **custom** two-AZ VPC (public ALB/NAT subnets + private service subnets). It does not use the default VPC. Tear down when finished — NAT and ALB hours add cost while the lab is
  up.
</Aside>
