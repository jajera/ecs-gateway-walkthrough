## Gateway infrastructure role

ECS assumes this <Tooltip term="infrastructure-role" label="infrastructure role" /> to create ALBs, security groups, ACM certificates, and related resources in your account. Attach the AWS managed policy `AmazonECSInfrastructureRoleForGatewayHostSharedALB`.

Your caller also needs `iam:PassRole` on this role when running `create-gateway` (AdministratorAccess includes it).

```bash
aws iam create-role \
  --role-name "${NAME}-gateway-infra" \
  --assume-role-policy-document '{
    "Version": "2012-10-17",
    "Statement": [{
      "Effect": "Allow",
      "Principal": { "Service": "ecs.amazonaws.com" },
      "Action": "sts:AssumeRole"
    }]
  }' \
  --query 'Role.RoleName' --output text

aws iam attach-role-policy \
  --role-name "${NAME}-gateway-infra" \
  --policy-arn arn:aws:iam::aws:policy/AmazonECSInfrastructureRoleForGatewayHostSharedALB

GATEWAY_INFRA_ROLE_ARN=$(aws iam get-role \
  --role-name "${NAME}-gateway-infra" \
  --query Role.Arn --output text)
export GATEWAY_INFRA_ROLE_ARN
echo "gateway infra role ready: ${NAME}-gateway-infra"
```

Do not paste role ARNs into docs or tickets — they embed the account ID. Keep `$GATEWAY_INFRA_ROLE_ARN` in your shell for later pages.

<Aside type="note">IAM is eventually consistent. If `create-gateway` fails with an assume-role error, wait about a minute and retry.</Aside>

## Task execution role

Both Fargate and EC2 `awsvpc` tasks use this role to pull images and write logs (`CreateLogStream` / `PutLogEvents`). It does **not** include `logs:CreateLogGroup` — each path’s services page creates the log group with your caller identity. Your caller also needs `iam:PassRole` on this role when registering task definitions / creating services.

```bash
aws iam create-role \
  --role-name "${NAME}-exec" \
  --assume-role-policy-document '{
    "Version": "2012-10-17",
    "Statement": [{
      "Effect": "Allow",
      "Principal": { "Service": "ecs-tasks.amazonaws.com" },
      "Action": "sts:AssumeRole"
    }]
  }' \
  --query 'Role.RoleName' --output text

aws iam attach-role-policy \
  --role-name "${NAME}-exec" \
  --policy-arn arn:aws:iam::aws:policy/service-role/AmazonECSTaskExecutionRolePolicy

EXEC_ROLE_ARN=$(aws iam get-role \
  --role-name "${NAME}-exec" \
  --query Role.Arn --output text)
export EXEC_ROLE_ARN
echo "task execution role ready: ${NAME}-exec"
```
