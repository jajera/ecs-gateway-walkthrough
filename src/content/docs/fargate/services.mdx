## Log group

`AmazonECSTaskExecutionRolePolicy` can write log **streams**, but not create the **group**. Create the group with your caller identity (do not use `awslogs-create-group` — that needs `logs:CreateLogGroup` on the exec role).

<div class="ecsx-cli">

```bash frame="terminal"
aws logs create-log-group --log-group-name "/ecs/${PATH_NAME}" 2>/dev/null || true
```

```text
(no stdout — created, or already exists)
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
aws logs put-retention-policy --log-group-name "/ecs/${PATH_NAME}" --retention-in-days 7
```

```text
(no stdout — success is silent)
```

</div>

## Task definitions

`awsvpc` + named port `web` (must match the connector `portName`). CPU/memory required for Fargate. HTML is base64-encoded so the task JSON stays tidy.

<Aside type="note">
  Baking the page HTML straight into the task definition is a **demo shortcut** — it keeps the lab to one self-contained task with no extra build or storage. Real apps don't do this: you'd bake
  content into your container image, or serve it from a volume, S3 + CloudFront, or an app backend. Here it just gives Orders and Catalog visibly different pages so you can tell which service the
  gateway routed to.
</Aside>

Define helpers once in this shell (no AWS call yet):

```bash frame="terminal"
write_app_html() {
  local out="$1" title="$2" accent="$3" blurb="$4"
  cat > "$out" <<HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <title>${title} · ECS Gateway lab</title>
  <style>
    :root { color-scheme: light dark; --accent: ${accent}; }
    * { box-sizing: border-box; }
    body {
      margin: 0; min-height: 100vh; display: grid; place-items: center;
      font-family: "Segoe UI", system-ui, sans-serif;
      background:
        radial-gradient(1200px 600px at 10% -10%, color-mix(in oklab, var(--accent) 28%, transparent), transparent 60%),
        radial-gradient(900px 500px at 100% 0%, color-mix(in oklab, var(--accent) 16%, transparent), transparent 55%),
        #0f1419;
      color: #e8eef5;
    }
    main {
      width: min(36rem, calc(100% - 2rem));

      border-radius: 1rem;

    }
    .eyebrow {
      margin: 0 0 .65rem; font-size: .75rem; letter-spacing: .14em;

}

register_web_task() {
  local family="$1" html_file="$2"
  local b64
  b64=$(base64 -w0 < "$html_file")
  cat > /tmp/${family}-task.json <<EOF
{
  "family": "${family}",
  "networkMode": "awsvpc",
  "requiresCompatibilities": ["FARGATE"],
  "cpu": "256",
  "memory": "512",
  "executionRoleArn": "${EXEC_ROLE_ARN}",
  "containerDefinitions": [{
    "name": "web",
    "image": "public.ecr.aws/nginx/nginx:stable-alpine",
    "essential": true,
    "entryPoint": ["sh", "-c"],
    "command": ["echo '${b64}' | base64 -d > /usr/share/nginx/html/index.html && exec nginx -g 'daemon off;'"],
    "portMappings": [{
      "name": "web",
      "containerPort": 80,
      "protocol": "tcp",
      "appProtocol": "http"
    }],
    "logConfiguration": {
      "logDriver": "awslogs",
      "options": {
        "awslogs-group": "/ecs/${PATH_NAME}",
        "awslogs-region": "${AWS_REGION}",
        "awslogs-stream-prefix": "web"
      }
    }
  }]
}
EOF
  aws ecs register-task-definition \
    --cli-input-json "file:///tmp/${family}-task.json" \
    --query 'taskDefinition.{family:family,revision:revision}'
}
```

## Service A (Orders)

Tasks run in **private** subnets with `assignPublicIp=DISABLED`. Omit security groups to use the VPC default (fine for this lab). First connector attachment provisions the shared ALB in the **public** subnets for this gateway.

<div class="ecsx-cli">

```bash frame="terminal"
aws ecs create-service \
  --cluster "$CLUSTER" \
  --service-name "${PATH_NAME}-a" \
  --task-definition "${PATH_NAME}-a" \
  --desired-count 1 \
  --launch-type FARGATE \
  --network-configuration "awsvpcConfiguration={
    subnets=[${PRIVATE_SUBNET_A},${PRIVATE_SUBNET_B}],
    assignPublicIp=DISABLED
  }" \
  --gateway-connectors '[{
    "portName": "web",
    "filters": { "accessTypes": ["PUBLIC"] },
    "healthCheck": { "healthCheckPath": "/" }
  }]' \
  --query 'service.{name:serviceName,status:status,desired:desiredCount}'
```

```text
{
    "name": "ecs-gw-lab-fargate-a",
    "status": "ACTIVE",
    "desired": 1
}
```

</div>

Same connector shape — platform already defined ingress on the Fargate-path gateway.

<div class="ecsx-cli">

```bash frame="terminal"

  --cluster "$CLUSTER" \
  --service-name "${PATH_NAME}-b" \
  --task-definition "${PATH_NAME}-b" \
  --desired-count 1 \
  --launch-type FARGATE \
  --network-configuration "awsvpcConfiguration={
    subnets=[${PRIVATE_SUBNET_A},${PRIVATE_SUBNET_B}],
    assignPublicIp=DISABLED

  --gateway-connectors '[{
    "portName": "web",
    "filters": { "accessTypes": ["PUBLIC"] },
```
