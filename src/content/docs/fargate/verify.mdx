## Wait for routes

Break only when every listed status is `ACTIVE` (not merely “no longer in progress”).

<div class="ecsx-cli">

```bash frame="terminal"
for i in $(seq 1 60); do
  STATUSES=$(aws ecs list-gateway-routes --gateway "$GATEWAY" --cluster "$CLUSTER" \
    --query 'gatewayRoutes[].status' --output text)
  echo "$i: $STATUSES"
  BAD=$(echo "$STATUSES" | tr '\t' '\n' | grep -cv '^ACTIVE$' || true)
  [ "$BAD" = "0" ] && [ -n "$STATUSES" ] && break
  sleep 10
done
```

```text
1: CREATE_IN_PROGRESS CREATE_IN_PROGRESS
2: CREATE_IN_PROGRESS ACTIVE
3: ACTIVE ACTIVE
```

</div>

## Service URLs

Define a helper that resolves a service’s managed HTTPS URL (route ARNs are not printed):

<div class="ecsx-cli">

```bash frame="terminal"
url_for() {
  local svc="$1"
  local arn
  arn=$(aws ecs list-gateway-routes --gateway "$GATEWAY" --cluster "$CLUSTER" \
    --service "$svc" \
    --query 'gatewayRoutes[0].gatewayRouteArn' --output text)
  aws ecs describe-gateway-route --gateway-route-arn "$arn" \
    --query 'gatewayRoute.serviceUrl' --output text
}

URL_A=$(url_for "${PATH_NAME}-a")
URL_B=$(url_for "${PATH_NAME}-b")
echo "a: $URL_A"
echo "b: $URL_B"
```

```text
a: https://ec-<orders-id>.ecs.ap-southeast-6.on.aws
b: https://ec-<catalog-id>.ecs.ap-southeast-6.on.aws
```

</div>

Poll until each page title matches (tasks may still be pending / draining right after a deploy):

<div class="ecsx-cli">

```bash frame="terminal"
for i in $(seq 1 48); do
  TITLE_A=$(curl -sS --max-time 15 "$URL_A" 2>/dev/null \
    | sed -n 's/.*<h1>\([^<]*\)<\/h1>.*/\1/p' | head -1 || true)
  TITLE_B=$(curl -sS --max-time 15 "$URL_B" 2>/dev/null \
    | sed -n 's/.*<h1>\([^<]*\)<\/h1>.*/\1/p' | head -1 || true)
  echo "$i: a=${TITLE_A:-?} b=${TITLE_B:-?}"
  [ "$TITLE_A" = "Orders" ] && [ "$TITLE_B" = "Catalog" ] && break
  sleep 10
done
```

```text
1: a=? b=?
2: a=Orders b=?
3: a=Orders b=Catalog
```

</div>

<div class="ecsx-cli">

```bash frame="terminal"
echo "Orders  -> $URL_A"
echo "Catalog -> $URL_B"
```

```text
Orders  -> https://ec-<orders-id>.ecs.ap-southeast-6.on.aws
Catalog -> https://ec-<catalog-id>.ecs.ap-southeast-6.on.aws
```

</div>

## Shared ALB check

Print load balancer **names** only (strip the ARN prefix so account IDs stay out of the paste buffer):

<div class="ecsx-cli">

```bash frame="terminal"
for ARN in $(aws ecs list-gateway-routes --gateway "$GATEWAY" --cluster "$CLUSTER" \
  --query 'gatewayRoutes[].gatewayRouteArn' --output text); do
  aws ecs describe-gateway-route --gateway-route-arn "$ARN" \
    --query 'gatewayRoute.resources.hostSharedAlb[0].loadBalancerArn' \
    --output text | awk -F: '{print $NF}'
done
```

```text
loadbalancer/app/ecs-gateway-alb-<id>/…
loadbalancer/app/ecs-gateway-alb-<id>/…
```

</div>

Both lines should match — one host-shared ALB for both services on this gateway.

<Aside type="note">
  There is **no Route 53 record in your account** for these URLs. The `*.ecs.<region>.on.aws`
  hostnames live in an AWS service-managed zone — you would only use Route 53 if you put your own
  custom domain in front of the gateway.
</Aside>
